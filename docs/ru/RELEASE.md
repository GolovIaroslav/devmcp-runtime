# Подготовка релиза

Проверьте ветку, единую версию, CHANGELOG, документацию, wheel/sdist,
clean-install, security gates, dogfood loop и secret scan дерева и истории.

Подготовка не публикует репозиторий, не переименовывает GitHub repository, не
сливает main, не публикует ChatGPT app и не создаёт GitHub Release. Целевая
версия — `v0.1.0-beta.1`; при нарушенном обязательном gate нужно отчитаться
как об alpha.

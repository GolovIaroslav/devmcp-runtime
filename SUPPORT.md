# Support

For a bug, include `devmcp --version`, the relevant command, platform, and a
redacted diagnostic. Never include tokens, private keys, full environment dumps,
or secret file contents.

- Security vulnerability: follow [SECURITY.md](SECURITY.md).
- Runtime behavior: check [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md).
- ChatGPT integration: check [docs/CHATGPT.md](docs/CHATGPT.md).
- Feature request: describe the user workflow and the policy impact.
